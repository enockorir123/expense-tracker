Expense Tracker
This is a simple Expense Tracker built with React and Vite. It allows you to add, view, search, and delete expenses. The app helps you keep track of your expenses and provides a simple interface to manage your finances.

Features
1.Add a new expense with description, amount, and date.
2.View all added expenses in a list.
3.Search expenses by description.
4.Delete an expense.

Tech Stack

1.React
2.Vite
3.JavaScript

Deployment

The app is deployed and live on Vercel. You can access the deployed version here:https://expense-tracker-three-peach.vercel.app/
